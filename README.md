# DungeonZero

8번 출구류 장르 게임 개발 프로젝트.

< 핵심 플레이 목표 > 
최대 4명의 플레이어가 협동하며 판타지 세상에서 자신의 이상현상을 찾아라.
각 플레이어는 스테이지마다 자신의 이상현상을 찾거나 이상현상이 없음을 확인해야 한다.
모든 플레이어가 자신의 이상현상을 찾으면 돌아가고, 아니라면 나아간다.

< 플레이어 역할 >
1. 마법사 : 다른 사람에게는 보이지 않고, 자신만 보이는 이상현상이 있을 수 있다.
2. 궁수 : 점프를 통해 높은 곳에 있는 이상현상을 찾아라. (다른 사람도 이상현상이 보임)
3. 전사 : 물체를 옮겨서 숨겨진 이상현상을 찾아라. (다른 사람도 이상현상이 보임)
4. 도적 : 스테이지마다 한 명의 능력을 복제해서 팀원을 도와라.

< 1차 필요 시스템 >
1. 스테이지 시스템
2. 랜덤 이상현상 배치 시스템
3. 역할 시스템
4. 역할 어빌리티 컴포넌트
5. 세이브 포인트 시스템
6. 메인 타이틀 및 옵션 시스템

< 2차 필요 시스템 >
1. 이상현상 발생 컴포넌트
